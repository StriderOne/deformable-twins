# VI с инициализацией posterior равной prior

[[Q-0001]] · [[H-0001]] · [[P-0002]] · [[B-0001]] · [[BL-0004]]

## Proposal
Повторить VI с posterior, изначально равным prior, чтобы убрать искусственно узкую инициализацию из [[E-0001]]. Остальные численные настройки сохраняются; authoritative параметры — [YAML](../../experiments/E-0002.yaml).
Сравнение: MAP из [R-0001](../../runs/R-0001/manifest.json), узкий VI из [R-0002](../../runs/R-0002/manifest.json), их оценка [R-0003](../../runs/R-0003/manifest.json). Повторно обучать MAP не требуется.

## До запуска
Проверить полные обучающие траектории нескольких samples из prior с backward. При нечисловых значениях остановиться, сохранить ошибку и не пересэмплировать для сокрытия неудачи.
Код и план фиксируются Git-коммитом до исполнения; точный execution commit будет указан в manifests и обзоре результатов.

## Ограничения
Исходные ограничения данных, data-dependent prior, mean-field, усечение градиентов и насыщение жёсткостей сохраняются. Большая ширина присутствует уже при инициализации, поэтому выполнение критерия ширины само по себе не подтверждает гипотезу. Требуются анализ изменения, fit и сходимости.
Статус proposal сохраняется из-за неизвестной provenance съёмки и CMA-ES; фактические исполнения регистрируются отдельно.
