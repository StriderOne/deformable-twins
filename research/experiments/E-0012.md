# Частота обновления параметров VI

Связанные документы — [[E-0011]], [[Q-0001]], [[H-0001]], [[P-0005]].

Исследователь запросил сравнение интервалов обновления 42, 7 и 1 переход на сервере homa@100.64.0.3 при бюджете 300 итераций. Рабочее прочтение бюджета — 300 полных проходов траектории для каждого варианта.

Proposal — проверить, позволяют ли более частые обновления получить сопоставимую ошибку предсказания за меньшее время. Предлагается исходная инициализация E-0011, общий seed и одинаковый набор случайных выборок для оценки. При обучении предполагается сохранять базовый случайный шум внутри прохода и распределять KL пропорционально числу переходов между обновлениями. Изменяющиеся внутри прохода параметры создают приближённую схему VI.

Исполняемый план будет оформлен после определения критерия сравнения. Результатов пока нет.

- [x] Human input required — Исследователь подтвердил описательный пилот без численного порога близости. Сравниваем попружинные отношения posterior std / prior std с итоговым [[E-0011]], ошибки траектории и время. Интерпретация приемлемости принадлежит исследователю после просмотра результатов.
